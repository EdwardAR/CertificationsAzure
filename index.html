02 / CONTEXTO

Azure en una página

0+servicios cloud

pago por usoescalaseguridadautomatización
01

Cloud concepts

Modelos público, privado e híbrido; IaaS, PaaS, SaaS; responsabilidad compartida.

02

Servicios core

Compute, redes, almacenamiento, identidad y bases de datos para resolver necesidades reales.

04 / CERTIFICACIÓN
AZ-900

Azure Fundamentals

Para quién

Personas que quieren demostrar fundamentos cloud y entender cómo se organiza Azure.

Resultado

Podrás conversar sobre arquitectura, servicios, costos y gobierno con criterio.

Conceptos cloud25–30%

Modelos cloud, beneficios, consumo, IaaS/PaaS/SaaS.

Arquitectura y servicios35–40%

Regiones, recursos, compute, redes, storage e identidad.

Gestión y gobernanza30–35%

Costos, Policy, portal, CLI, Monitor, Advisor y seguridad.

→ Empieza por AZ-900 si quieres una visión transversal de cloud.
05 / CERTIFICACIÓN
DP-900

Azure Data Fundamentals

Para quién

Personas que comienzan a trabajar con datos y necesitan distinguir cargas y servicios.

Pregunta guía

¿Qué tipo de dato tengo y qué experiencia necesito construir sobre él?

Conceptos de datos25–30%

Estructurado, semiestructurado, no estructurado; transaccional vs. analítico.

Datos relacionales20–25%

SQL, normalización y Azure SQL Database, Managed Instance y VM.

No relacional + analítica40–55%

Blob, Files, Tables, Cosmos DB, ingesta, streaming, Fabric y Power BI.

→ Elige DP-900 si te interesan SQL, analítica, reporting o ingeniería de datos.
06 / CERTIFICACIÓN · FOCO IA
AI-901

Azure AI Fundamentals

✦AI
Para quién

Personas que comienzan en IA y quieren entender cómo se construyen soluciones modernas en Azure.

Lo que cambia

La ruta ya no se queda en teoría: conecta conceptos de IA con implementaciones en Microsoft Foundry.

Conceptos y capacidades de IA40–45%

IA responsable, modelos generativos y agentic AI; texto, voz, visión y extracción de información.

Implementación con Microsoft Foundry55–60%

Prompts, despliegue de modelos, chat, agentes y aplicaciones ligeras con SDK y Foundry Tools.

Responsible AI→modelos→Foundry→agentes y apps
→ Elige AI-901 si quieres comprender y prototipar soluciones de IA generativa en Azure.
07 / CERTIFICACIÓN
GH-900

GitHub Foundations

Para quién

Usuarios de GitHub, perfiles técnicos y no técnicos que colaboran en proyectos digitales.

Diferencia clave

No es Azure: es la base para trabajar y colaborar con fluidez en GitHub.

Git y GitHub25–30%

Version control, commits, branches, GitHub Flow, cuentas y organizaciones.

Repositorios y colaboración20–30%

README, issues, pull requests, discussions, Pages, Wikis y notificaciones.

Desarrollo moderno10–15%

GitHub Actions, Copilot, Codespaces y editores para trabajar mejor.

Projects, seguridad y comunidad20–35%

Projects, permisos, 2FA, administración, open source y Marketplace.

→ Elige GH-900 si tu día a día gira en torno a repositorios, PRs y colaboración.
